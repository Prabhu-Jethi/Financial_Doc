# Financial Document Intelligence — Frontend

A minimal, lightweight Next.js + React JavaScript frontend for the Financial Document Intelligence Engine.

## Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: Pure JavaScript / JSX (No TypeScript)
- **Dependencies**: Only `next`, `react`, and `react-dom` (Zero additional libraries)
- **Styling**: Standard CSS (`globals.css`)

## Quickstart

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install the minimal dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
